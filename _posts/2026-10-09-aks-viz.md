On AKS Automatic, a node's page shows its YAML and events. What I wanted to know was what is on this node, and how full is it?

I investigated where to run it: simplest would be creating a web app in a container, but that requires resources in the cluster and configuration of identity and access. Recently AKS Desktop also got an update that I hadden't looked at yet, so decided to target that. 

AKS Desktop is built on Headlamp and a plugin uses the signed-in user's own cluster credentials. The plugin adds a Node view to the sidebar. You pick a node pool and each node gets a column with: Node status, CPU and memory details, pods with a status dot.
